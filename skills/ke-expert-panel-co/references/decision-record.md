# Expert-panel decision record

| Item | Content |
| --- | --- |
| Decision | What must be chosen? |
| Constraints | Budget, time, policy, platform, data |
| Options | Up to three viable approaches |
| Role views | PM / BA / SA / Engineer / Tester |
| Recommendation | Choice and rationale |
| Risks / mitigations | Owner and action |
| Open questions | Only decision-changing questions |
