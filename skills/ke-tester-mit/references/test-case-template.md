Use separate cases for validation, lookup, calculation, role access, approval
transition, notification, and regression when they apply.

Use only `PASS`, `FAIL`, `BLOCKED`, or `NOT RUN`. Configuration evidence,
API evidence, and browser evidence are not interchangeable.
