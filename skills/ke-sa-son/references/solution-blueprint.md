# Solution blueprint

| Design area | Required decision |
| --- | --- |
| Apps | Purpose, owner, app relationship, record lifecycle |
| Data model | Field codes/types, unique keys, calculated values, attachments |
| Master data | Source app/system, lookup key, refresh ownership |
| Access | Role, app/record/field permissions, audit requirement |
| Workflow | Statuses, transitions, roles, notification triggers |
| Integration | Direction, API/auth owner, mapping, retry/error handling |
| Operations | Views, reporting, backup/export, support ownership |
