# Synthetic sample data

These files contain fictional data only. Use them to practise the KE discovery,
survey-analysis, BRD, solution-design, and testing flows.

- `survey-responses.csv`: sanitized discovery-survey responses.
- `purchase-requests.csv`: example transaction records for a purchase-request
  process.

Do not replace these files with customer exports. Put raw customer survey data
under `projects/<project-slug>/99-private/`.
